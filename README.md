Document Generation & Summarization App

Features:
- Company Registration: Name Approval, DSC, DIN, MOA, AOA, Certificate of Incorporation
- Other License Registration: Income Tax, GST, Import-Export, FSSAI, Shop & Establishment, Drug
- Summarization: Simple text summarizer

Run (use Command Prompt):
1) cd C:\Users\MEENA\OneDrive\Desktop\docum-1
2) npm i express cors multer pdfkit uuid
3) npm i -D nodemon
4) npm run dev
5) Open http://localhost:3000

Files:
- public/index.html, public/styles.css, public/main.js
- src/server.js (Express server and PDF generation)
- uploads/ (auto-created for generated PDFs)
