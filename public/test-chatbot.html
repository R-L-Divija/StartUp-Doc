🤖 Chatbot Test Page

What to look for:

  • Green circular button at bottom-right corner with headset icon
  • Red notification badge with "2" on the button
  • Prominent "Need Help?" button above the circular button
  • Navbar "Chat Assistant" button (if navbar exists)

How to test:

  • Click the green circular button to open the chatbot
  • Try asking questions like "What services do you offer?"
  • Click the quick question buttons in the chatbot
  • Check if the chatbot responds properly

Expected behavior:

  • Chatbot should open when clicking any of the buttons
  • Should show typing indicators when responding
  • Should provide helpful responses about IDM services
  • Should close when clicking the X button

If you don't see the chatbot buttons, check the browser console for any JavaScript errors.
